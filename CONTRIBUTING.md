# Contributing

dbt charts is developed in a private upstream repository and mirrored here read-only.

## Pull requests

Not accepted. Changes pushed to this repository cannot reach the upstream, so any pull
request opened here will be closed unmerged. We plan to open up external contributions
in the future.

## Issues

Bug reports and feature requests are welcome:
[open an issue](https://github.com/dbt-labs/dbt-charts/issues/new/choose).

Because a follow-up pull request from you is not an option here, please include enough
detail to reproduce in one pass — the bug template asks for the package version, your
environment, and a minimal board YAML plus the command you ran.

## Security

Do not open a public issue for a vulnerability. See
[SECURITY.md](https://github.com/dbt-labs/dbt-charts/blob/main/SECURITY.md).

## Questions

Documentation lives at [docs.dbtcharts.com](https://docs.dbtcharts.com). To try board
YAML without installing anything, use [play.dbtcharts.com](https://play.dbtcharts.com).
