# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Report vulnerabilities to **security@fivetran.com**. Include:

- A description of the vulnerability and its impact
- Steps to reproduce, or a proof of concept
- The affected version(s) of `dbt-charts` or `dbt-charts-playground`

This repository is mirrored from a private upstream, so fixes are made
there before being published here. You will not see a fix land as a pull
request against this repository.

## Response expectations

We will acknowledge your report within 5 business days and keep you
updated as we investigate and address the issue.

## Supported versions

Only the latest published release of each package is supported with
security fixes.
